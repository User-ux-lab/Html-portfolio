# Shayne's Portfolio

A modern, responsive web portfolio showcasing web development projects.

## Features

✨ **Fully Responsive Design** - Mobile-friendly layout that works on all devices
🎨 **Modern Styling** - Clean, professional design with gradient backgrounds
🔗 **Easy Navigation** - Intuitive navigation between portfolio pages
📄 **Complete HTML Structure** - Valid, semantic HTML across all pages
⚡ **Performance Optimized** - Lightweight CSS with smooth transitions

## Pages

- **Home (`index.html`)** - Main portfolio landing page with featured projects
- **Movie Ranking (`public/movie.html`)** - Top 3 favorite movies with descriptions
- **Birthday Invite (`public/bday.html`)** - Birthday celebration event page
- **About Me (`public/about.html`)** - Personal biography and background
- **Contact (`public/contact.html`)** - Contact information and details

## File Structure

```
Html-portfolio/

│   ├── bday.html          # Birthday invite project
```

## Styling

The portfolio uses a modern color scheme with:
- Primary Color: `#667eea` (Purple Blue)
- Secondary Color: `#764ba2` (Deep Purple)
- Background Gradient: Linear gradient for visual appeal
- Responsive breakpoints for mobile optimization

## How to Use

1. Open `index.html` in a web browser
2. Navigate through the portfolio using the menu
3. Click on projects to see detailed pages
4. Use contact page to reach out
